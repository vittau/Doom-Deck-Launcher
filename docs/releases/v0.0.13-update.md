# DoomDeckLauncher v0.0.13-update

This experimental Steam Deck update brings the signed Flatpak and GitHub tarball
forward together from the same source commit.

- Switch Discover and Library between Cards and a compact List with Select (or V on
  a keyboard). The two tabs share the choice, preserve focus and remember it after closing.
- When a catalog needs a newer DDL, the manual check now names the required version
  and asks for an application update.
- Flatpak AppStream metadata now uses the workspace version automatically at build
  time. Publication checks compare its installed display version with the binary and
  verify the exported source commit.
- Includes the existing 118-recipe catalog and the reviewed publication-wait repair.

Install or update the signed Flatpak from [doomdecklauncher.com](https://doomdecklauncher.com/).
Existing installations can update with:

```sh
flatpak update --user com.doomdecklauncher.DoomDeckLauncher
```

The GitHub assets provide the Linux x86_64 tarball and SHA-256 checksum. IWADs are
never included. DSDA-Doom is downloaded from its official upstream at runtime.

Physical Steam Deck checks for the new browsing mode, package version in Discover,
controller behavior and saved preferences remain pending. The automated Linux tests
and signed-install smoke checks do not replace those hardware checks.
