# DoomDeckLauncher v0.0.15-local

This experimental Steam Deck update brings the reviewed local-content improvements and clearer
recipe controls to both the GitHub tarball and the signed Flatpak from the same source commit.

- Adding local content is responsive: choosing a folder now lists files without hashing every
  byte, and the selected files are identified only when you confirm them. A long listing can be
  cancelled, and the app remembers the last usable folder.
- A missing custom-setup file can be located in its own slot or profile, without rebuilding the
  setup. Identical content is repaired silently; different bytes ask before they replace it.
- New custom setups take the first content filename as their name and can be renamed later
  without touching profiles or saves.
- Show recipe variants replaces the old Advanced row. Mapsets without free recipe alternatives
  keep the row visible but greyed out and skipped by focus; where alternatives exist, opening
  them reveals and focuses the first one, and replacing a selection still asks for confirmation.
- Compatibility on catalog mapsets now states Set by recipe instead of offering a control that
  could not change anything. Custom setups keep Auto and numeric compatibility.
- Discover keeps its category filters and chronological order; the Discover and Library
  Cards/List choice is shared. Screenshots now cover 114 of the 118 catalog recipes.
- Headless Chicken now selects MBF21 in the catalog after a Boom crash.
- AppStream and binary versions are both **0.0.15**.

Install or update the signed Flatpak through [doomdecklauncher.com](https://doomdecklauncher.com/):

```sh
flatpak install --user --from https://doomdecklauncher.com/com.doomdecklauncher.DoomDeckLauncher.flatpakref
```

The GitHub assets provide the Linux x86_64 tarball and its SHA-256 checksum. IWADs are never
included, and DSDA-Doom is downloaded from its official upstream at runtime.

Focused offline local-content, navigation, ordering and rendering checks passed, together with
the offline catalog lint. Physical Deck checks are still pending: controller and Steam-keyboard
feel for local content, Flatpak folder visibility, SD-card behavior, the greyed-out variant row
contrast, the recipe-controlled compatibility note, how the new screenshots render on the Deck,
and the owner's upgrade. See [the manual checks](https://github.com/vittau/Doom-Deck-Launcher/blob/v0.0.15-local/docs/deck-testing.md).
