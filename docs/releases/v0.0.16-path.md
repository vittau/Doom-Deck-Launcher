# DoomDeckLauncher v0.0.16-path

A small experimental update that shortens the folders DDL creates for installed mapsets.

- Install folders used to be named after the whole release citation, so a mapset could live in
  a path like `.../headless-chicken/RC1 2023-12-09, RC14 2026-01-19 (readme, day-first date);
  idgames archive file dated 2026-02-02/free/HDLSCHKN.wad`. The folder is now a short label
  derived from the release, for example `.../headless-chicken/RC1-2023-12-09/free/HDLSCHKN.wad`.
  Plain version labels such as `1.23` keep their existing names.
- Nothing about downloads, verification, profiles, saves or launch arguments changed. The
  shorter folder is created by a new install.
- After updating, mapsets installed by an older build are not migrated: **uninstall and install
  the mapset again** to get the short folder. This build has no other player-visible change.
- AppStream and binary versions are both **0.0.16**.

Install or update the signed Flatpak through [doomdecklauncher.com](https://doomdecklauncher.com/):

```sh
flatpak update --user com.doomdecklauncher.DoomDeckLauncher
```

The GitHub assets provide the Linux x86_64 tarball and its SHA-256 checksum. IWADs are never
included, and DSDA-Doom is downloaded from its official upstream at runtime.

Focused library tests and the ordinary Linux CI checks passed. This build exists to test on the
Steam Deck whether a shorter install path changes the Headless Chicken crash that the owner
reported at DSDA-Doom 0.30.1; that result is not known yet. Physical Deck validation of local
content and recipe variants from the previous release is still pending, and the manual checks
are in [the Deck checklist](https://github.com/vittau/Doom-Deck-Launcher/blob/v0.0.16-path/docs/deck-testing.md).
