# DoomDeckLauncher v0.0.17-discover

A small experimental update to browsing in Discover.

- The category strip now stays fixed at the top of Discover while you scroll, in both Cards and
  List view, so the open category is always visible. Mapsets scroll beneath it and the focused
  card or row is always shown in full. Choosing another category returns the list to the top.
- Discover cards are more compact: 340 px tall instead of 410 px, with a taller screenshot and
  the tags on a single row of smaller chips. When two tags do not fit, only the first one (the
  open category) is shown. Library cards and List rows are unchanged.
- Nothing about downloads, verification, profiles, saves or launch arguments changed.
- AppStream and binary versions are both **0.0.17**.

Install or update the signed Flatpak through [doomdecklauncher.com](https://doomdecklauncher.com/):

```sh
flatpak update --user com.doomdecklauncher.DoomDeckLauncher
```

The GitHub assets provide the Linux x86_64 tarball and its SHA-256 checksum. IWADs are never
included, and DSDA-Doom is downloaded from its official upstream at runtime.

Focused UI tests and the full Linux test suite passed. Headless Chicken still crashes with
DSDA-Doom 0.30.1 on Linux; the fix is proposed upstream in
[dsda-doom#1050](https://github.com/dsda-org/dsda-doom/pull/1050) and needs a new engine release.
Physical Deck feel of the pinned strip and the readability of the smaller tags are not validated
yet; the manual checks (PD1–PD3) are in
[the Deck checklist](https://github.com/vittau/Doom-Deck-Launcher/blob/v0.0.17-discover/docs/deck-testing.md).
