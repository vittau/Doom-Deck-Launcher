# DoomDeckLauncher v0.0.18-favorites

A small experimental update to the order of mapsets in Discover.

- Every Discover category, in Cards and List, now lists your mapsets first: installed
  favorites, then other installed mapsets, then favorites you have not installed yet, then the
  rest. Inside each group the order stays chronological (release date, then title).
- Marking or unmarking a favorite, or finishing an install, moves the mapset to its new group
  right away and keeps the focus on it.
- In the Favorites category, removing the focused favorite now moves the focus to the next
  card (or the last one, or the Favorites chip when the list becomes empty) instead of leaving
  it on a card that is no longer shown. The same applies after unfavoriting on the mapset page.
- Nothing about downloads, verification, profiles, saves or launch arguments changed.
- AppStream and binary versions are both **0.0.18**.

Install or update the signed Flatpak through [doomdecklauncher.com](https://doomdecklauncher.com/):

```sh
flatpak update --user com.doomdecklauncher.DoomDeckLauncher
```

The GitHub assets provide the Linux x86_64 tarball and its SHA-256 checksum. IWADs are never
included, and DSDA-Doom is downloaded from its official upstream at runtime.

The ordinary offline test suite, the category and favorites journey and the Linux CI checks
passed. Headless Chicken still crashes with DSDA-Doom 0.30.1 on Linux until an engine release
contains [dsda-doom#1050](https://github.com/dsda-org/dsda-doom/pull/1050). Physical Deck checks
for this order (DF1–DF2) are in
[the Deck checklist](https://github.com/vittau/Doom-Deck-Launcher/blob/v0.0.18-favorites/docs/deck-testing.md).
