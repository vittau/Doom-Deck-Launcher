# DoomDeckLauncher v0.0.19-menu

A small experimental update to how games start.

- Every game now opens at DSDA-Doom's title screen and menu instead of dropping you straight
  into the first map. Pick New Game, the episode and the skill there, or load a save. This
  applies to catalog mapsets, base games, custom setups and Home → Continue.
- DDL no longer has its own skill setting: the Skill row is gone from Play setup, base-game
  setup and the profile summary, and `ddl launch` no longer accepts `--skill`. Existing
  profiles keep working; their old skill value is simply ignored.
- Pistol start is unchanged: with it on, every map after the first still starts with only the
  pistol, also for a game started from DSDA-Doom's menu.
- Catalog recipes can no longer prescribe a starting map; no recipe used one.
- AppStream and binary versions are both **0.0.19**.

Install or update the signed Flatpak through [doomdecklauncher.com](https://doomdecklauncher.com/):

```sh
flatpak update --user com.doomdecklauncher.DoomDeckLauncher
```

The GitHub assets provide the Linux x86_64 tarball and its SHA-256 checksum. IWADs are never
included, and DSDA-Doom is downloaded from its official upstream at runtime.

Formatting, denied-warning Clippy, the ordinary offline test suite (1,019 tests) and catalog
lint passed. Headless Chicken still crashes with DSDA-Doom 0.30.1 on Linux until an engine
release contains [dsda-doom#1050](https://github.com/dsda-org/dsda-doom/pull/1050). Physical
Deck checks for this change (MM1–MM4) are in
[the Deck checklist](https://github.com/vittau/Doom-Deck-Launcher/blob/v0.0.19-menu/docs/deck-testing.md).
