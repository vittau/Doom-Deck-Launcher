# DoomDeckLauncher v0.0.20-progress

An experimental update that shows how far you are in each mapset, read from DSDA-Doom's own
statistics.

- **Progress on Library cards:** installed mapsets, base games and custom setups show
  `N/M maps` for the selected profile, with a progress bar on catalog mapset cards.
- **Progress on the mapset page:** a summary with a bar and a per-map table: map, done, exits,
  highest skill, kills % and secrets %. A map counts as done once DSDA-Doom recorded a skill
  for it, so exits with no monsters do not count.
- **UV-Max mark:** a trophy marks maps where the recorded skill is Ultra-Violence or higher and
  the best kills and best secrets reach the map's totals. DSDA-Doom keeps each best on its own,
  so they may come from different runs; this is not a verified single-run UV-Max.
- **Honest totals:** the total is the maps DSDA-Doom found in the mapset's own WADs. A recipe
  can leave out an ending or test map; Abandon leaves out its short closing MAP18.
- DDL only reads `stats.txt`; it never writes, repairs or deletes it. Before you finish your
  first map in a setup, the page says there are no DSDA-Doom stats yet instead of showing 0.
  Each profile keeps its own progress, and adding an extra WAD starts a separate one.
- Stats are read only for DSDA-Doom 0.30.1, the engine version whose format was audited.
- Catalog updates now need DDL 0.0.20 or newer, because recipes can carry the new
  `[progress]` table.
- AppStream and binary versions are both **0.0.20**.

Install or update the signed Flatpak through [doomdecklauncher.com](https://doomdecklauncher.com/):

```sh
flatpak update --user com.doomdecklauncher.DoomDeckLauncher
```

The GitHub assets provide the Linux x86_64 tarball and its SHA-256 checksum. IWADs are never
included, and DSDA-Doom is downloaded from its official upstream at runtime.

Formatting, denied-warning Clippy, catalog lint and the ordinary offline test suite passed.
Headless Chicken still crashes with DSDA-Doom 0.30.1 on Linux until an engine release contains
[dsda-doom#1050](https://github.com/dsda-org/dsda-doom/pull/1050). Physical Deck checks for this
release (PG1–PG6) and for 0.0.19's menu launch (MM1–MM4) are in
[the Deck checklist](https://github.com/vittau/Doom-Deck-Launcher/blob/v0.0.20-progress/docs/deck-testing.md).
