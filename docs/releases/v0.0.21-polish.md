# DoomDeckLauncher v0.0.21-polish

An experimental update that makes per-mapset progress easier to see.

- **Progress first on the mapset page:** the Progress summary and its bar now sit above the
  description, so they show without scrolling. The per-map table follows the profile, and a long
  profile summary ends with "…" instead of running into it.
- **Custom setups get a bar:** a custom setup's Library card shows its `N/M maps` with the same
  progress bar as catalog mapsets. Base-game cards keep the text-only count.
- **Progress on base games and custom setups:** their pages now show the same summary, bar and
  per-map table as a catalog mapset, with UV-Max, Kills and Secrets. The table is read-only:
  the D-pad stays on the buttons and the right stick scrolls it.
- **Ending maps left out:** Arrival's MAP10 and Haste's MAP17 are short ending maps and no
  longer count toward their totals (10 and 17 maps). This came through the catalog and also
  applies to 0.0.20.
- AppStream and binary versions are both **0.0.21**.

Install or update the signed Flatpak through [doomdecklauncher.com](https://doomdecklauncher.com/):

```sh
flatpak update --user com.doomdecklauncher.DoomDeckLauncher
```

The GitHub assets provide the Linux x86_64 tarball and its SHA-256 checksum. IWADs are never
included, and DSDA-Doom is downloaded from its official upstream at runtime.

Formatting, denied-warning Clippy, catalog lint and the ordinary offline test suite passed.
Headless Chicken still crashes with DSDA-Doom 0.30.1 on Linux until an engine release contains
[dsda-doom#1050](https://github.com/dsda-org/dsda-doom/pull/1050). Physical Deck checks for this
release (PP1–PP3) are in
[the Deck checklist](https://github.com/vittau/Doom-Deck-Launcher/blob/v0.0.21-polish/docs/deck-testing.md).
