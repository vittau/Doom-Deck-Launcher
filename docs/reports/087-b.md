### DeHackEd decision (all six)

Every release embeds a `DEHACKED` lump. The four archives that also ship an external `.deh`
(DTWID, NEIS, D2TWID, REKKR) ship the older, vanilla-engine-only or identical form: DTWID's 2011 external file
names `E2M3: Rec Center` where the 2012 embedded patch says `E2M3: Rec Facility`; NEIS's
readme says the external file is "only necessary for Vanilla/Chocolate Doom"; D2TWID's
external file uses legacy `Text` blocks while the embedded WhackEd4 patch has
`[STRINGS]`/`[PARS]` and names MAP33. REKKR's external `REKKR.deh` is byte-identical to its embedded 61,321-byte lump (same
SHA-256), so loading both would apply the total-conversion patch twice. DSDA-Doom applies
embedded DEHACKED from explicitly loaded PWADs even under `-noautoload`, so none of the
recipes adds a separate `-deh`; the tests assert no `dehacked` component exists. This is confirmed from upstream source and
needs a Deck look for the visible intermission names.

## Decisions and deviations worth the coordinator's attention

1. **Sunder release pin.** The author's newest release, V.2512 (announced 2025-10-02, adds
   MAP21), is linked through OneDrive, which is not an allowed download host. Rather than
   change host policy, the recipe pins the author's preceding **V.2407** Dropbox build
   (22 slots: MAP01–MAP20 + MAP31/32). This satisfies "pin a specific public release" but
   the catalog entry is one update behind; if the owner wants V.2512, the host allowlist
   would need a reviewed change. The older DSDA 14-map dataset was deliberately not used.
2. **Sunder readme mismatch.** Its own header says `Map 01 - Map 19 (+31 & 32)` while the
   WAD has MAP20 and the readme documents Map 20. The recipe and research state the
   inspected 22-slot scope, not the stale header.
3. **Sunder artwork** was not bundled: DoomWiki's two MAP11 gallery images are only 162-px
   thumbnails and their original size/licence could not be verified from bytes.
4. **DTWID is not tagged `megawad`** even though Cacowards prose calls it one: 27 maps is
   below the 30-map definition. It is also not `episode` (27 > 9).
5. **Deathless is not tagged `cacowards`**: no award could be confirmed. It carries
   `classics` on release age plus the readme's official-add-on credit.
6. **REKKR is the free PWAD edition only.** The recipe is a PWAD over the player's Ultimate
   Doom IWAD; the standalone IWAD and paid Sunken Land releases are not acquired, declared or
   assumed. Its external `REKKR.deh` is byte-identical to the embedded lump, so it is not loaded
   separately.
7. Shared `crates/ddl-core/src/catalog/tests.rs` still asserts the pre-087 expected-id set;
   as instructed, I did not repair it. Coordinator integration owns that change.
