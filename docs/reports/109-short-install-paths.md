## What changed

`Installer::install_dir` used the recipe's whole `release` label as the per-release directory
name. Catalogue `release` is player-facing citation text, so paths could look like
`library/headless-chicken/RC1 2023-12-09, RC14 2026-01-19 (readme, day-first date); idgames
archive file dated 2026-02-02/free/HDLSCHKN.wad` — hundreds of characters with spaces, commas,
parentheses and a semicolon.

The directory name is now `release_dir_name(release)`: keep the leading label, drop a trailing
citation from the first `(`, `;` or `,`, keep ASCII letters, digits, `.`, `_` and `-`, collapse
separators, trim edges and bound the result to 32 bytes; a label with nothing usable becomes
`release`. Plain labels (`1.23`, `RC14`) are unchanged, so paths that were already short stay
put. Headless Chicken becomes `library/headless-chicken/RC1-2023-12-09/free/HDLSCHKN.wad`.

Member paths, sizes, SHA-256 identities, download caching, recipe freezing, profiles, launch
arguments and uninstall/retirement checks are untouched. Nothing is migrated: per D-042 the
project is experimental and breaking layout changes are allowed, so the owner reinstalls a
mapset to adopt the short folder. That is stated in the release notes.
