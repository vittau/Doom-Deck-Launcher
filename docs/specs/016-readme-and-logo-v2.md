**Status:** Done  ·  **Milestone:** M2  ·  **Depends on:** 013, 014
**Owner request (2026-10-16):** "Melhora o README.md: menos verboso; logo melhorado/novo; bote

## Goal

A short, attractive README that sells DDL in one screen (logo, one-line pitch, screenshots,
install in a few steps), with the detailed Steam Deck setup moved to a dedicated guide — and a
stronger logo than the current "Ember Gate".

## Requirements

- **R1** — **Logo v2 (owner picks):** three original logo concepts in the Ember Cathedral
  identity (D-020, D-021), each shown as emblem + wordmark lock-ups on dark and light at 32, 64
  and 256 px in one contact sheet per concept, under `docs/design/logo-v2/`. Original only — no
  id Software / Bethesda marks and no DOOM-logo imitation. Final mark stays a clean SVG master
  (spec 013 R2 rules). The owner picks one; until then nothing in the app changes.
- **R2** — **Apply the picked logo** everywhere spec 013 placed the current one (app header,
  loading, About, window icon, Steam artwork in `ddl/art/`, README, social preview), regenerated
  by the existing export script.
- **R3** — **README (short):** logo; one-sentence pitch; 3–4 screenshots (Home, Discover, Play
  setup, Mapset detail) from the headless renders, committed under `docs/screenshots/` at a
  readable size; a "Features" list of at most 6 bullets; "Install on Steam Deck" in ≤ 6 steps;
  links to the guide (R4), the catalog contribution guide and the licence. Target: fits roughly
  two screens on GitHub; no long prose.
- **R4** — **`docs/steam-deck-guide.md`:** everything detailed that leaves the README — the
  Steam Input / controller layouts (spec 011 content, unchanged in substance), "Do not set a
  Compatibility tool", Steam artwork customization (spec 013), Konsole troubleshooting with the
  `ddl` subcommands (spec 014), logs location, FAQ. README links to it.
- **R5** — **Screenshots stay reproducible:** a script or test target regenerates
  `docs/screenshots/*.png` from the headless renders (documented in the guide's maintainer note).
