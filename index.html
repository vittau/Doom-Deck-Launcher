DoomDeckLauncher

Signed Flatpak builds, served from this site. Version 0.0.9, published 2026-10-21.

Install on a Steam Deck (Desktop Mode → Konsole):

flatpak install --user --from \
  https://www.vitormach.dev/Doom-Deck-Launcher/io.github.vittau.Doom-Deck-Launcher.flatpakref

The runtime comes from Flathub, which SteamOS already has configured. The Flatpak and its updates are signed by this project's repository key, embedded in the .flatpakref; no extra remote or manual key import is needed.

Update

flatpak update --user io.github.vittau.Doom-Deck-Launcher

Discover also picks the update up on its next check. Installed mapsets, engines and profiles live in ~/.var/app/io.github.vittau.Doom-Deck-Launcher/ and survive updates.

Uninstall

flatpak uninstall --user io.github.vittau.Doom-Deck-Launcher

Add --delete-data to remove the app's data directory as well.

Add it to Steam

In Desktop Mode, add a non-Steam shortcut pointing at /usr/bin/flatpak with launch options run io.github.vittau.Doom-Deck-Launcher, then set Compatibility tool: none. The Flatpak carries its own runtime.

What this is not

  • Not a Flathub release: there is no store page and no Flathub review.
  • Not validated on hardware yet: GL, audio, controller input, IWAD visibility and the on-screen keyboard still need a Steam Deck pass.
  • The DSDA-Doom engine is downloaded at runtime from its official upstream release and is never bundled here. IWADs are never downloaded.

Details

  • Repository URL: https://www.vitormach.dev/Doom-Deck-Launcher/repo/ (branch stable)
  • Full remote file: ddl.flatpakrepo
  • Source and build instructions: github.com/vittau/Doom-Deck-Launcher
  • Older builds are pruned after two versions; flatpak update always moves forward.

Published automatically from tagged builds. If an install fails, check flatpak remote-ls ddl and open an issue with the output.
