↓ Install on Steam Deck

Signed Flatpak · Experimental channel

  1. Download & open in Discover

    Switch to Desktop Mode and use the install link. Open the downloaded .flatpakref file from your browser’s downloads or Dolphin; choose Discover if asked. Review the source and permissions, then select Install. Downloading the file alone does not install DDL.

  2. Add the launcher to Steam

    In Steam, choose Games → Add a Non-Steam Game. Select DoomDeckLauncher if listed. Otherwise browse to /usr/bin/flatpak and set launch options to run @@APP_ID@@. Rename the shortcut to DoomDeckLauncher.

    In Properties → Compatibility, leave Force a compatibility tool off (tool: none).

  3. Bring your games. Find a map.

    Launch DDL, install the official DSDA-Doom engine and add a folder containing your own IWADs. Return to Gaming Mode, configure your controller layout, then discover and install a compatible mapset.

An independent, experimental channel

This is a pre-alpha, self-hosted Flatpak repository signed with the project’s key. It is not a Flathub listing or a Flathub-reviewed build. The install ref includes the repository key; runtimes come from Flathub.

DSDA-Doom is downloaded separately from its official upstream release. DDL is built with Rust and Slint, with AI assistance under its human maintainer’s direction and review.

Updates & other downloads

Check Discover for launcher updates from this signed remote. Engine and catalog updates stay inside DDL; your installed mapsets, profiles and saves survive app updates.

Prefer an archive? Download ddl-linux-x86_64.tar.gz and its checksum from GitHub Releases. Extract, keep the folder together and add the ddl executable to Steam. Tarball setup guide.

Konsole fallback & repository details
Still experimental

These Discover instructions describe the expected install flow. Installation, controls and gameplay still need testing on a physical Steam Deck. See the Deck checklist below for what remains.

If the downloaded file does not open in Discover, install it from Konsole in Desktop Mode: 

flatpak install --user --from @@SITE_BASE@@/@@APP_ID@@.flatpakref

Update the launcher:

Uninstall the launcher (app data is kept unless you also pass --delete-data):

Before you install

Questions, answered.

What DoomDeckLauncher is, what it needs from you, and what it leaves to the games you already own.

What is DoomDeckLauncher?

DoomDeckLauncher (DDL) is a free, open-source launcher for Steam Deck that keeps community DOOM mapsets, curated load order, engine settings, profiles and saves in one controller-first library. It starts mapsets with DSDA-Doom. It is an independent project, not a DOOM re-release and not a game download service.

Is it free, and what is the license?

Yes. DDL is free software under GPL-3.0-or-later, with no account, subscription or paid tier. You still need to own the DOOM games whose IWAD files you add.

Does it include DOOM or the mapsets?

No commercial base game is bundled or downloaded. You point DDL at a folder holding your own IWADs, and DDL installs community mapsets from their published releases. Mapset imagery and credits stay with their authors.

Which source port does it use?

DSDA-Doom only. The official engine release is downloaded separately from its upstream project inside DDL. GZDoom and other source ports are not supported.

How do installation and updates work?

Download the signed .flatpakref, open it in Discover in Desktop Mode and install. Discover then delivers launcher updates from this self-hosted experimental remote — not Flathub. Engine and catalog updates arrive inside DDL, and installed mapsets, profiles and saves survive app updates. A ddl-linux-x86_64.tar.gz archive is available on GitHub Releases instead.

Is it made for Steam Deck?

DDL is designed controller-first for Steam Deck, with a Linux Flatpak build; no Windows or macOS builds are published. Installation happens in Desktop Mode, then you add the launcher to Steam and return to Gaming Mode. Hardware validation is still in progress: the install flow, controls and gameplay still need testing on a physical Deck.
